# Data Sources

This document records exactly where every dataset used in VitaeMX comes from, under what license, how current it is, and which fields are actually used. It exists so that every figure in the application can be traced back to a public, verifiable source.

## Primary source: CONAPO

**Dataset:** *Conciliación demográfica de México 1950-2019 y Proyecciones de la Población de México y las Entidades Federativas 2020-2070*
**Publisher:** Consejo Nacional de Población (CONAPO), Government of Mexico
**URL:** https://conapo.segob.gob.mx/work/models/CONAPO/pry23/PP/index.html (also mirrored at https://www.datos.gob.mx/dataset/proyecciones-de-poblacion)
**License:** Open data published under Mexico's federal open data policy (datos.gob.mx) — free to use, reuse, and redistribute with attribution.
**Update cadence:** Revised periodically by CONAPO (the current vintage used is the 2023 projection round, "pry23"); the fetch date for the cached copy in `data/raw/` is recorded in that folder's own README.
**Fields used:** age-specific mortality probability (`qx`) and survivors (`lx`), by sex, by state, by calendar year.
**Role in VitaeMX:** primary and authoritative source for all life tables. See [`docs/adr/0003-conapo-as-primary-source.md`](docs/adr/0003-conapo-as-primary-source.md) for why this was chosen over deriving tables from raw death counts.

## Secondary source: INEGI

**Dataset:** *Estadísticas de Defunciones Registradas (EDR)*
**Publisher:** Instituto Nacional de Estadística y Geografía (INEGI)
**URL:** https://www.inegi.org.mx/programas/edr/
**License:** Open data, free to use with attribution, per INEGI's terms of use.
**Update cadence:** Published annually, with a roughly one-to-two-year lag (registered deaths take time to finalize).
**Fields used:** raw registered death counts by age, sex, state, and (for later phases) cause of death.
**Role in VitaeMX:** cross-validation only in Phase 1 — used to sanity-check that CONAPO's smoothed `qx` values are consistent with the underlying raw registrations, not as a direct input to the life tables. Becomes a primary input in the Phase 4 cause-of-death work (see [`ROADMAP.md`](ROADMAP.md)).

## Reference source: WHO Global Health Observatory

**Dataset:** *Global Health Estimates — Life tables*
**Publisher:** World Health Organization (WHO)
**URL:** https://www.who.int/data/gho
**Methods documentation:** https://cdn.who.int/media/docs/default-source/gho-documents/global-health-estimates/ghe2021_lifetable_methods.pdf
**License:** Free to use for non-commercial purposes with attribution, per WHO's data policy.
**Update cadence:** Published in estimate rounds (current: 2000–2021 round).
**Fields used:** national-level life tables for international comparison.
**Role in VitaeMX:** benchmarking only — lets the app show how Mexico's mortality profile compares internationally. Not used to build Mexico's own tables.

## Data lineage

Raw snapshots are cached in `data/raw/` with a fetch date recorded, since none of these sources offer a stable versioned API — re-fetching is a manual, documented step, not an automated pipeline in Phase 1. Processed outputs in `data/processed/` are regenerated by the notebooks in `research/` and are what the backend actually serves; the processed files record which raw snapshot and which notebook run produced them.

## A note on currency

Official Mexican demographic data is published on multi-year cycles, not in real time. VitaeMX states the vintage of the data it is using directly in the application (via the `/api/methodology-version` endpoint described in [`ARCHITECTURE.md`](ARCHITECTURE.md)) rather than implying the figures are current-day.
