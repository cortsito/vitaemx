# data/processed/ — data dictionary

Everything the backend serves. Regenerated by the notebooks in `research/`; never edited by hand. Reference year and raw-file checksums are in `version.json`.

Keys shared by all files: `state_code` (0 = national, 1–32 = states in INEGI order), `sex` (`total`, `male`, `female`), `age` (single years 0–109).

## `life_tables.csv` — notebook `01_build_life_tables.ipynb`

| Column | Meaning |
|---|---|
| `state_name` | CONAPO's entity name |
| `mx` | central death rate, deaths ÷ mid-year population (empty beyond the closing age) |
| `qx` | probability of dying between x and x+1; 1 at the closing age |
| `lx` | survivors at exact age x, `l0 = 100000` |
| `dx` | deaths between x and x+1 |
| `Lx` | person-years lived between x and x+1 |
| `Tx` | person-years lived after age x |
| `ex` | life expectancy at age x |

## `fitted_qx.csv` — notebook `02_fit_gompertz_makeham.ipynb`

| Column | Meaning |
|---|---|
| `qx_fitted` | Gompertz-Makeham `qx` for ages inside the fitting window, raw `qx` outside it |
| `qx_source` | `fitted` or `raw` |

## `gompertz_makeham_params.csv` — notebook `02`

One row per (state, sex): `A`, `B`, `c` of `μ(x) = A + B·c^x`; `r2_log_mu` and `rmse_log_mu` on the fitting window; `age_min`, `age_max` (30, 90).

## `validation_e0.csv` — notebook `03_validate_life_expectancy.ipynb`

One row per (state, sex): `e0_vitaemx` (from `life_tables.csv`), `e0_conapo` (CONAPO's published `EV`/`EVH`/`EVM`), `difference_years`.

## `version.json` — notebook `02`

Methodology version, data source, reference year, run date, raw file SHA-256s, fit window and life-table constants.
